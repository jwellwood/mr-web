# AGENTS

Follow the conventions in [.github/copilot-instructions.md](.github/copilot-instructions.md).

## Communication

- Answer directly for simple requests. No preamble or summary.
- Do not ask for confirmation unless the task is ambiguous or high-impact.

## Workflow

**Small tasks** (≤2 files, no new components): implement directly.

**Medium/large tasks** (new feature, multiple files, or unclear scope):

1. Investigate the request.
2. Identify files that require changes.
3. Produce a brief implementation plan.
4. STOP and wait for user approval.
5. After approval: make only the approved changes. Do not expand scope.
